UML Project: Library Management System

Members search, borrow, and return books. Librarians manage the catalog.

1. Use case diagram

flowchart LR
  M([Member]) --> U1((Search books))
  M --> U2((Borrow book))
  M --> U3((Return book))
  L([Librarian]) --> U4((Manage books))
  L --> U5((Collect fines))
  U5 -.->|extends| U3

2. Activity diagram

flowchart TD
  S((Start)) --> A[Member searches for a book]
  A --> B{Book available?}
  B -->|Yes| C[Librarian issues the book]
  C --> D[Member returns the book]
  D --> E((End))
  B -->|No| F[Member reserves the book]
  F --> E

3. Sequence diagram

sequenceDiagram
  actor Member
  participant System
  participant Database
  Member->>System: Request to borrow a book
  System->>Database: Check availability
  Database-->>System: Book is available
  System-->>Member: Confirm due date
