Hosting Tools for Our Websites

To share a website, we store the code online and then publish it.

GitHub

Stores our code and tracks every change. Good for saving projects and working in a team.

Vercel

Connects to a GitHub project and publishes it with a live link. Good for fast publishing.

Render

Hosts websites, servers, and databases. Good for projects that need a back end.

How we publish

  1. Upload the files to a GitHub repository (name the main file index.html).
  2. Import the repository into Vercel or Render.
  3. Copy the live link and share it.
