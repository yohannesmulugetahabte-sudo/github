Class 1 – Thursday

Introduction to UML diagrams

We learned that UML (Unified Modeling Language) is a standard way to draw how a system works before building it. Our teacher gave us a group presentation on three diagram types: activity, use case, and sequence. Each group got one system to model: hospital, library, or business. Class 3 – Thursday

Tools to host and store our websites

We learned that a website on your own computer is not visible to anyone else. Tools like GitHub, Vercel, and Render store the code and publish it online so anyone can open it with a link.

Group project: Library Management System

Our group modeled a library where members search, borrow, and return books and librarians manage the catalog. Below are our three UML diagrams.

Use case diagram

Shows who uses the system (actors) and what they can do.

Activity diagram

Shows the step-by-step flow of borrowing and returning a book.

Sequence diagram

Shows the order of messages between the member, system, and database.

Hosting tools for our websites

To share a website we store the code online and then publish it. Here are the three tools from our class.

GitHub

Stores our code and tracks every change. GitHub Pages can also publish simple sites. Good for saving projects and working in a team.

Vercel

Connects to a GitHub project and publishes it with a live link, updating on every change. Good for fast publishing of websites.

Render

Hosts websites and also back-end servers and databases. Good for projects that need a server, like a library system with a database.
